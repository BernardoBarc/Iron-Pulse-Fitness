Projeto de estudos onde foi pedido 
para que o chat GPT sugerisse uma ideia de landing page para 
trabalhar melhor a semantica, estrutura html e estilização com CSS junto com JavaScript.
No projeto não foram usadas diversas ferramentas, usei apenas o Web3Forms 
para ter um formulario de contato funcional.
Ao olhar o projeto pode-se perceber que a chave de envio está amostra, porém, em
caso de uso por terceiros, o que deve ser feito é que o usuario crie uma conta na plataforma e substitua a key pela que foi gerada no site da plataforma.

Abaixo segue os atributos solicitados pelo Chat GPT para que fosse criada a landing page

Lembrando que por fazer parte de um estudo, não trabalhei tanto a parte de responsividade em outras telas, somente na tela do computador
Outro detalhe é referente ao nome da "empresa", esse nome foi totalmente
inventado pelo Chat GPT, então não foi "roubado" o nome para que pudesse ser feito esse projeto de estudos.

Algumas exigências técnicas

Como sou bem exigente com qualidade, gostaria que o desenvolvedor seguisse algumas boas práticas:

HTML semântico (header, main, section, article, footer etc.).
Navegação por âncoras.
IDs apenas onde realmente forem necessários.
Classes reutilizáveis.
Layout totalmente responsivo (desktop, tablet e mobile).
CSS organizado e de fácil manutenção.
JavaScript separado em um arquivo próprio.
Animações suaves, sem exageros.
Código limpo e bem indentado.
